# SpinEat · 今天吃甚麼

選擇困難？拉一下，幫你決定今天吃甚麼。

## 功能

- 🎰 **拉霸抽選**：拉霸捲軸動畫，結果可以「就吃這個」或「再抽一次」（再抽時會略過剛剛那一項）
- 🔍 **分類篩選**：餐別（依目前時間自動選擇）、預算、料理類型
- 📅 **最近吃過排除**：記錄吃過的餐點，自動排除最近 N 天內吃過的選項（可調 1–7 天或關閉）
- 🏪 **我的店家**：主頁可切換「料理」或「我的店家」模式；抽中店家時可直接開啟 Google 地圖
- ⚙️ **設定頁**：管理店家（名稱、地址、餐別、預算、分類標籤、啟用開關）與分類標籤
- 💾 **備份**：匯出／匯入 JSON，可用來搬資料到其他裝置

紀錄與設定存在瀏覽器的 localStorage，不需要後端。

## 本機執行

純靜態網頁，任選一種方式啟動：

```bash
python -m http.server 5173
```

然後打開 http://localhost:5173

## 專案結構

```
index.html      主頁（拉霸機）
settings.html   設定頁（店家、標籤、備份）
css/style.css   樣式（支援深色模式）
js/foods.js     內建料理清單
js/store.js     共用資料層（localStorage 讀寫、匯出匯入）
js/app.js       拉霸捲軸、篩選、紀錄邏輯
js/settings.js  設定頁邏輯
```
